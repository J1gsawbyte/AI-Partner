##  关于`configs\modules\long_memory.json`的配置

| key                                                  | 备注                                          |
| ---------------------------------------------------- | ------------------------------------------- |
| `global_memory`                                      | 是否启用**全局记忆**<br>启用后会导致所有允许写入记忆的会话异步写入同一个记忆库 |
| `memory_whitelist`                                   | **允许写入记忆的白名单**对话qq号/群聊号                     |
| `summarize_rounds`<br>`summarize_interval_minutes`   | 历史会话达到多少条或者程序开启时间达到多少分钟<br>即开始调用总结记忆任务      |
| `embedding_enabled`                                  | 是否启用embedding模型进行**记忆库检索**                  |
| `embedding_model_path`<br>`embedding_tokenizer_path` | 设定embedding模型必要文件的路径                        |
##  关于`configs\modules\ai_typing_delay.json`的配置
| key                        | 备注                               |
| -------------------------- | -------------------------------- |
| `msg_delay_base_range`     | 每次发送消息时AI会延迟的**基础时间**的随机范围(秒)    |
| `msg_delay_per_char_range` | 发送消息时模拟打字时间对**每个字符**进行的延迟随机范围(秒) |
| `msg_delay_max`            | 每次发送消息时AI会延迟的**最大值**(秒)          |
